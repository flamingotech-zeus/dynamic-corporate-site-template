# 动态风格企业官网模板

[English](README.md) | [简体中文](README.zh-CN.md)

> 单色酸（Monochrome Acid）风格的企业官网首页模板 —— 纯 HTML/CSS/JS，含一整套动效系统。

> **说明。** 这个仓库里带有具体公司的内容 —— 品牌文案、标志、资源路径。真正值得拿走的是版式、动效和代码。发布前请先替换内容。


## 这是什么

这不是那种滚动加个淡入就叫动态的模板。这里的动效是分层且有纪律的，而这件事比听起来难做。

整站只跑三种颜色。不是三种加点缀 —— 就是三种。每一个板块、每一个悬停态、每一次过渡都收在这个约束里，所以它看起来是一套成形的设计，而不是一堆效果的集合。

## 为什么开源

这是给我们自己的站点做的，后来内容换了几轮，这套样式系统留下了。

内容是我们的，设计系统不是。这里能拿走的是配色的纪律、动效的层次、以及板块的组织方式。把文案和标志换掉，就是一套能直接用的站。

## 里面有什么

- **三色系统。** 米白画布、近黑、酸性荧光绿。是定死的，不是"从这里再加"的起始色。
- **一整套开场序列。** 预加载计数、多栏色幕揭幕、标题逐字入场、副标题与按钮的分级淡入 —— 而不是页面直接出现。
- **分层背景。** 流动光雾、透视网格地面、巨型描边跑马灯、带呼吸波与指针涟漪的半调点阵画布、锥形渐变光环、光泽球体、虚线轨道、旋转星芒。
- **滚动视差。** 背景五层以不同速率位移。
- **板块处理。** 带滚动视差的巨型描边幽灵标题、逐字入场的章节标题、整块酸绿配巨型数字的数据区。
- **HUD 层。** 取景框叠加、等宽字体的时间码与章节标记，以及覆盖全站的固定胶片颗粒层。
- **版本档案。** `VERSIONS.md` 记录了每一轮改了什么，设计决策可追溯。

## 环境要求

任意静态文件服务器。没有构建步骤、没有框架、没有依赖。

## 怎么开始

直接用浏览器打开 `index.html`，或者把目录起成一个静态服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

把文案、标志和链接换掉，就是你的站。

## 注意与边界

1. **动效密度是设计意图。** 分层背景在不同机器上的帧率不一样。要在真正在意的那台设备上测过。
2. **值得处理"减少动态效果"的系统偏好。** 这套动效强度足够大，尊重这个偏好是正经事，不是走形式。
3. **颗粒和模糊层是要吃 GPU 的。** 就是它们让观感对了，性能掉了的时候也是它们最先该减。
4. **内容带具体公司信息。** 换掉它；这个仓库里有价值的是结构。
